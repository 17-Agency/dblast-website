Problemi comuni

Errore «No module named 'scipy'» (o un altro modulo) all'avvio del backend

L'ambiente virtuale non è attivo o mancano le dipendenze. Attiva backend/.venv e rilancia pip install -r backend/requirements.txt.

La porta 5173, 8000 o 8080 è già occupata

Un altro processo usa la porta: chiudilo. Per il backend puoi usare un'altra porta (uvicorn backend.main:app --port 8001), ma allora imposta di conseguenza VITE_PROXY_TARGET e VITE_RISK_PROXY_TARGET.

Il canvas resta vuoto, o l'API risponde 409 «graph not built yet»

Il backend è avviato ma nessun database è stato caricato. Connettiti dal form di connessione del frontend (serve il kernel), oppure avvia il backend con DBLAST_SEED_MOCK=1 per precaricare i dati di prova.

Errore di rete in connessione

Il kernel non è raggiungibile su DBLAST_KERNEL_URL (di default http://localhost:8080): avvia il kernel con kernel\kernel.bat.

pytest non trova il modulo backend

Lancialo dalla radice del repository, non da backend/.
